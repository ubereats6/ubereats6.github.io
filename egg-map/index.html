WINDOWS HUD · 正式版

搶蛋地圖輔助 HUD

F8 鎖定／解鎖　F9 隱藏／顯示

把地圖浮在遊戲上方，邊玩邊對照。可調大小、透明度，也能鎖定避免誤觸。首次啟動HUD需要一些時間準備，地圖資料自動從本站更新。

下載 Windows EXE v18 · Windows 64 位元
  1. 開啟程式下載 EXE，雙擊即可使用。
  2. 找出地圖選難度及兩個門的方向，再挑候選；需要時用截圖比對。
  3. 浮在遊戲上按「使用」後，滾輪縮放、滑鼠拖曳查看。
使用說明辨識只提供候選地圖，局部探索或畫面遮擋可能影響結果。截圖只在你的瀏覽器內處理，不會上傳到本站。

點「擷取目前地圖」後，請在瀏覽器視窗中選擇正在顯示地圖的遊戲視窗。只取一張畫面並立即停止分享；接著直接框選範圍。

擷取建議：保留起點金色門

擷取與框選範圍建議包含起點金色門，以及門周圍已探索的道路，提供較完整的地圖線索。避免只截到小段走道；若範圍太小或畫面有遮擋，候選結果仍可能不準確。

拖曳框選地圖範圍，建議保留起點金色門與周圍道路；若整張截圖只有地圖，可直接開始比對。
