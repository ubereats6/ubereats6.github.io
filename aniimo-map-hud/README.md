# 伊莫搶蛋地圖 HUD v9（Windows x64）

伊莫搶蛋地圖 HUD v9（Windows x64）

• 移除流程按鈕箭頭及 HUD 地圖方向按鈕，保留滾輪縮放與滑鼠拖曳。
• 框選畫面預設符合視窗寬度，不用先手動放大；高於顯示區的內容可捲動查看。
• 蛋圖示減少留白，提高 Windows 圖示內的視覺大小。
• 保留難度、即時預覽、四個候選、重新框選與圖標開關。

下載 AniimoEggMapHUD-Windows-x64-v9.zip，完整解壓縮後執行 AniimoEggMapHUD-Egg.exe，不需 Node.js。
F8 鎖定／解鎖；F9 隱藏／顯示。先關閉舊版。

## 使用步驟

1. 先關閉舊 HUD，再完整解壓縮新 ZIP，執行 AniimoEggMapHUD-Egg.exe。
2. 按「擷取辨識」。首次需選難度，之後記住上次選擇；開啟時保持解鎖。
3. 確認難度後到下一頁選來源，進入即時預覽／框選頁；建議包含起點金色門與周圍道路。滾輪可放大，開始框選就凍結當下畫面；放開後比對，也可按整張比對。畫面預設符合視窗寬度。
4. 候選縮圖可按「放大預覽」。也可按「重新框選」保留同張畫面和縮放重選範圍，或按來源旁的「更新畫面」或候選頁的「更新所選視窗畫面」恢復即時預覽。按「使用這張」才送至 HUD，四個候選缩圖保留在 HUD 下方。
5. 蛋固定顯示，其他五種圖標可切換；鑰匙顏色及圖標位置沿用網頁資料。
6. 滾輪／加減按鈕在 50%–400% 間縮放地圖，放大後以滑鼠拖曳移動。切換地圖重設為適合視窗的 100%。
7. 拖曳標題移動 HUD，拉視窗邊緣或右下角調整尺寸；最小 320×300。透明度 30%–100%。
8. F8 鎖定並讓滑鼠穿透；再按 F8 可調整。F9 隱藏／顯示。備用快捷鍵 Ctrl+Shift+M、Ctrl+Shift+J，系統匣雙擊也可解鎖。
9. 首次開啟會註冊 aniimo-egg-map:// 連結，網頁 v18 的「浮在遊戲上」可將編號送入本程式。

## 地圖池

簡單 8 張、困難 6 張、噩夢 7 張、渾沌 9 張，沿用資料的編號 31–60。只使用最新版地圖，不再讀取舊版遠端 JPG。
所選視窗僅在框選頁即時預覽，開始框選就凍結，離開框選頁或關閉辨識視窗會停止；不錄影，不寫入地圖池。使用者可開啟 PNG/JPG/WebP 截圖，但安裝資料內沒有 .png 圖片檔。
新增地圖需一起更新 maps.json、features.json、marker-layers.json 及相關 WebP，再重新打包；不會自動下載未知地圖。

## 驗證範圍

已通過語法、分步流程、來源限制、即時預覽更新與停止、縮放／拖曳／框選坐標、候選預覽與重新框選的模擬測試。地圖、比對核心和 HUD 圖層與使用者確認可用的 v7 相同，逐檔確認未變。這些結果不表示局部黑霧截圖必定正確。
Windows 的實際桌面擷取、快捷鍵與置頂顯示仍需實機確認；遊戲獨佔全螢幕若蓋過 HUD，可改用無邊框視窗。

## 開發

原始碼資料夾為 aniimo-map-hud/，package.json 版本 0.9.0；既有 GitHub Actions 建置工作流可繼續使用。Windows Portable 包使用既有 Electron Windows x64 執行環境，已替換成這一版 app 程式與離線資料。
